    Wobble on purpose: PS1 rendering in a browser

    The PlayStation drew 3D with whole-pixel screen coordinates and no perspective correction. The flaws that make 1997 look like 1997 all came from saving silicon. I wanted them back for this site’s header, and each one costs about ten lines of shader.

    1Snap every vertex to the pixel grid

    The console’s geometry coprocessor, the GTE, handed the rasterizer integer screen positions.1 No corner could sit between two pixels, so when the camera moved, every polygon hopped from one pixel to the next. In a vertex shader, that means rounding the clip-space position after projection:

    glsl · vertexpsx-snap.vert
    // after projection, before the rasterizer
vec4 p = projectionMatrix * viewMatrix * worldPos;
vec2 grid = uResolution * 0.5;   // pixels per NDC unit
p.xy = floor(p.xy / p.w * grid + 0.5) / grid * p.w;
gl_Position = p;

    Divide by w, round, multiply back. The multiply matters: the GPU divides by w again during rasterization, so the value you hand it has to land on the grid after that divide.

    2Let textures swim

    Perspective-correct texturing needs a divide per pixel, and the hardware skipped it. Texture coordinates were interpolated straight across the screen, so a floor tile bent along its diagonal as it turned toward you. WebGL always corrects for perspective, but you can cancel the correction: multiply the UV by w in the vertex shader, pass w along, and divide in the fragment shader.

    Field noteKeep polygons large. Affine warping only shows on big triangles, which is why PS1 artists subdivided their floors and why this scene doesn’t.

    3Fewer colours, then dither

    The frame buffer held 15-bit colour, five bits per channel. Quantize to 32 levels and the sky bands at once. Adding a 4×4 Bayer matrix before the rounding turns those bands into the crosshatch everyone remembers from CRT captures.

    • Render the scene to a target about a quarter of the canvas width.
    • Scale it up with nearest-neighbour filtering so each dither cell is a visible block.
    • Fog everything past 50 units. It hides the draw distance, as it did in 1997.

    Fill cost at that size is tiny. The real budget goes to draw calls, which is the next note.

    1. Geometry Transformation Engine, a fixed-point coprocessor in the CPU package. Its screen coordinates came out as 16-bit integers, which is where the snapping comes from. ↩

    Proposal notes · key to tags A–G

    Mock only. Content is placeholder. Toggle tags with a.

    A

    Hero sheets

    Three scenes, one subject each. 01 Ruins: columns, arch, fallen head, trees, fog, stars and moon. 02 Topo: live relief with marching-squares contours, index contour every 2.5 m, a draped 5 m survey grid and a sweep. 03 Astral: halo with glyphs, cored polyhedra, the watcher, the moon on its orbit. Only the active sheet renders. Switch with [ ] or the tabs; it dissolves through the dither matrix (hard cut under reduced motion) and remembers your last sheet. All three use the PS1 pipeline: ¼ resolution, 15-bit colour, Bayer dither, vertex snap, affine UVs, fog. x compares against a clean render.

    B

    Map frame

    Hero corners act as a sheet legend. Lat/lon, elevation, bearing and grid ref are read from the drifting camera; the compass turns with it. Landmarks carry pinned survey labels. Readouts, labels, map key and eyebrow change with each sheet (topo shows scale and contour interval; astral shows RA/Dec).

    C

    Keyboard layer

    Every nav item prints its chord. g starts a chord, / filters the index, ? lists all keys. The status line mirrors vim: mode, pending chord, selection.

    D

    Accent variants

    Four accents named for materials in the world. One switch rewrites CSS tokens and shader uniforms for all three sheets, and shifts fog and sky to suit. Lichen is the default.

    E

    Index as survey table

    Grid ref, kind, founding year, a 12-month activity profile drawn like an elevation section, and a map-key state symbol. Rows filter and expand in place.

    F

    Reading column

    Literata at 19 px / 1.68 on a 66-character measure: a screen-tuned book face with optical sizes, so headings and body share one family. Fragment Mono for keys, code and data. Silkscreen only for eyebrows, sheet numbers and 88×31s, where its pixel grid echoes the hero.

    Wordmark: “NCA” in Silkscreen, “Ventures” in Literata italic, in the accent. The initials sit on the hero’s pixel grid and the word sits in the reading face, so the name joins the two halves of the site.

    G

    Indie footer

    Webring with prev/next, 88×31 buttons drawn in CSS (no images), RSS, last-surveyed date. Square corners and hairline rules throughout; the only fills are the accent and the sheet.
