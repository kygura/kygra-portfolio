kygra writes software and makes things that print. Most of the code on this site is small, finished, and runs on one machine; most of the prints are two colours because the riso only has two drums. This is the fourth version of the site, which replaces the third, which was fine but looked like everyone else's.

Everything here is hand-typed. Writing is drafted in Notion and synced once a day. The catalogue lists every project with a number, because numbering things makes you finish them. If you want to talk, write.

Stamp

A static site generator that only knows one layout, because deciding on layouts is how projects die.

Year2026, March to September
StackRust, pulldown-cmark, minijinja
Roleeverything
Statuslive · v0.6.2
Repogithub.com/kygra/stamp
Livestamp.kygra.example
LicenseMIT

Stamp takes a folder of Markdown and produces a folder of HTML. It has one template, three front-matter keys, and no plugin system. I wrote it after spending a weekend configuring a generator that had all of those things and producing nothing.

The constraint turned out to be the feature. Every site built with Stamp looks like a printed index: a masthead, a ruled table of entries, a colophon. You can change the ink colour and the fonts. That is it.

Notes

Builds are incremental by content hash, not mtime, so a git checkout does not rebuild everything. The only clever part is the table-of-contents ordering, which sorts by date and falls back to filename when two posts share a day.

$ stamp build --ink "#C1272D"
  read   31 entries
  wrote  34 files
  done   48ms
